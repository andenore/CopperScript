26 / ANALYSIS IN THE COMPILER

Real numbers from the examples.

CIRCUIT SIMULATION

66.8 nV/√Hz

preamp output noise at 1 kHz. The bench’s own hand estimate: about 67. Five benches, with a 200-board Monte Carlo, in about 0.1 s.

EMI SCREENING

+49.6 dB

buck converter over the CISPR 32 class B average limit with no input filter; 6.4 dB under with an LC filter (and a 2 A load).

ANTENNA SYNTHESIS

2.37 GHz

monopole resonance after full-wave tuning, from 2.72 GHz for the quarter-wave template; 86 % radiation efficiency.

An agent can ask “is this good?” and get a number tied to the source, instead of a guess. Every one is evidence for review, not a qualification.

These numbers come from running the current compiler on the repository examples. The noise bench matches the engineer’s hand calculation written in the bench file. The EMI comparison shows what an input filter does, though the filtered example also declares a 2 A operating point instead of the current-limit worst case, so it is not the filter alone. The antenna example shows synthesis moving a textbook quarter-wave guess, which resonates 12 % high, onto the band.
