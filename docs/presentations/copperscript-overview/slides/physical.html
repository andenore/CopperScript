05 / PHYSICAL INTENT

Mechanics live in the same file.

mechanical {
    outline rectangle {
        width = 40mm; height = 30mm;
    }
    hole H1 {
        position = (3mm, 3mm); diameter = 2.2mm;
    }
}
constraint fixed_placement(R_ANCHOR) {
    x = 7mm; y = 8mm; side = front;
}
constraint antenna(ANT1.FEED) {
    bands = "2400 MHz-2483.5 MHz";
    ground = GND;
}

Board shape and fit

Outlines, curves, cutouts, holes, keepouts, component heights and datums.

Placement and routing

Fixed poses, regions, groups, widths, clearances, pairs and length matching.

Synthesized copper

Declare a band and a region; a full-wave model tunes the antenna trace.

Physical intent is source too. The mechanical block defines the board; constraints pin placement and routing rules. The antenna constraint is a good example of intent over geometry: you declare the band, the ground and the region, and the compiler synthesizes the trace and its matching network on a full-wave model of your board. A browser-based mechanical editor writes changes back to the source.
