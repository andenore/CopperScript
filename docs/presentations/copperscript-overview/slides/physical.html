Mechanics live in the same file.

mechanical {
    outline rounded_rectangle { width = 40mm;
        height = 30mm; corner_radius = 3mm; }
    slot MOUNT { start = (17mm, 10mm);
        end = (23mm, 10mm); width = 1.5mm; }
    hole H1 { position = (5mm, 25mm);
        diameter = 2mm; }
}
constraint fixed_placement(R1) {
    x = 8mm; y = 10mm; rotation = 0; side = front;
}

Outlines, curves, cutouts, slots, holes, keepouts, heights and datums; placement and routing rules sit beside them.

The example after route-board: both nets pass either side of the slot.

From the mechanical curves example. The source defines a rounded outline, a slot and a mounting hole, and fixes two resistors. The picture is that board after the standard route-board pipeline, drawn by copper render from its native Gerber plot; the slot and hole come from the plotted drill file, which copper render does not draw, so they were added at the drill file’s coordinates. Both tracks keep clear of the slot. A browser-based mechanical editor writes geometry changes back to the source.
