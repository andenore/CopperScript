Real output, trimmed, from searching the coin-cell project’s dependencies. The result names the part, its version and hashes, and the exact catalogue page, figure and URL its facts came from. An agent searches only the libraries the project declares, then inspects one section of one contract, so it spends its context on the facts it needs. The output also states its evidence level, here source declarations only, so nobody mistakes a declaration for a measurement.
