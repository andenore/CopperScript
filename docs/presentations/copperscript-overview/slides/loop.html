The agent never has to read the whole manual, re-parse its own source or write a one-off script to see what went wrong. The compiler already answers those questions.

The loop in commands. copper agent-guide gives a short bootstrap and topics such as syntax, libraries, verification, iteration and simulation. copper library search and inspect retrieve only the contracts the task needs. copper check --json returns located findings with machine-applicable fixes. copper explain describes a diagnostic code, copper query answers questions about the compiled design, and copper issues and copper view group routing failures and draw them.
