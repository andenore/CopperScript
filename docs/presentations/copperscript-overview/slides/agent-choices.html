23 / DESIGNED FOR GOOD DECISIONS

Six choices that keep an agent honest.

01

Text, not clicks

The agent writes source it can diff and explain. No GUI to drive, no hidden state.

02

Retrieve, don’t guess

Parts come from pinned libraries with datasheet facts. Unknown facts stay unresolved.

03

Units catch nonsense

Typed quantities and pin roles turn a wrong voltage or a fighting output into an error.

04

Compact, located feedback

Codes, lines, hints and fixes in versioned JSON. Summaries are bounded; details on request.

05

No silent passes

A missing input never becomes a pass. Stale results are refused. Screening is never a verdict.

06

Fix the method

Routing failures improve generic algorithms, compared with reference layouts, not one board.

Six design choices. One: text instead of a GUI, so the agent’s work is reviewable. Two: retrieval from pinned, versioned libraries, so it does not invent part data; facts the source does not give stay explicitly unresolved. Three: units and roles, so many wrong decisions fail to compile. Four: compact, located, machine-readable diagnostics, so the agent spends its context on the problem. Five: no silent passes; screening results and missing evidence stay visible. Six: when routing fails, the project improves the generic algorithm by comparing with manufacturer reference layouts, rather than adding board-specific patches.
