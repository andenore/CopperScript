CopperScript/demo/routing

The live routing lab on the project website. It compiles a small self-contained .copper board in the browser and runs the same copper-route pipeline as the native tool, with the same global routing, negotiation, exact commit checks and internal DRC, in a web worker. The default case weaves eight crossed signals around a keepout on two layers; this screenshot is from a local run of the current source: 8 of 8 connected, 12 vias, no DRC findings, in about 0.6 seconds. Other cases show a layer change and a blocked corridor, where the lab reports the open nets instead of showing a canned success. The geometry is synthetic teaching material, not a qualified circuit.
