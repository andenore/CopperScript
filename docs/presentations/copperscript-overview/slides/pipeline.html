Each stage writes JSON with a schema and the SHA-256 of its inputs. Changed inputs invalidate old evidence, and missing evidence stays visible instead of turning into a pass.

The whole flow runs from one source. Each step writes a report a person or an agent can read: compiled IR, simulation results, route reports, DRC and CAM read-back. Outputs record hashes of their inputs, so stale evidence is detected rather than reused. KiCad remains available as an independent cross-check and export target.
