04 / FACTS AND RELATIONSHIPS

Parts hold facts; boards hold intent.

library: part definition

part BME280 {
    category = "sensor.environmental";
    pin VDD {
        number = "1";
        domains = "power";
        voltage_min = 1.71V;
        voltage_max = 3.6V;
    }
}

Ratings come from the datasheet, with units. Put 5 V on this pin and the compiler says “5 V exceeds the pin maximum 3.6 V”, with the line.

board: component

component C_MCU: CAPACITOR {
    value = 100nF;
    role = decoupling;
    decouples = "U_MCU.VDD";
}

A relationship, not just a value. The pin association survives compilation and steers decoupling placement and how the capacitor feeds the pin.

Two layers of information. Library parts hold facts copied from datasheets, with units and source provenance. Board components hold relationships: this capacitor decouples that pin. Both survive compilation into the intermediate representation, so checks, placement and routing can act on them. The excerpts are shortened; the component is from the CopperAssetTracker board.
