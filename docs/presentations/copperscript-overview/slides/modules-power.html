09 / MODULES AND POWER STATES

Reusable circuits and declared power states.

module AnalogFrontEnd {
    port VP: power_in;
    port VN: power_in;
    // pump, buffers, receiver …
}

// board
module AFE: AnalogFrontEnd;
net VP { U_LDOP.OUT; AFE.VP; … }
power_state SLEEP {
    VP = off; … }

The impedance analyzer in SLEEP: VP is declared off, and the module sees it as AFE/VP. copper power-check checks every state for back-power.

The soil impedance analyzer example keeps its analog front end in a module with typed ports, instantiated once on the board; seventeen simulation benches target the module alone. The board declares power states such as MEASURE and SLEEP. The picture is CopperReview’s power view of that board with SLEEP selected: the positive analog rail VP and its regulator chain are declared off, and the selected rail shows its alias AFE/VP across the module boundary and its source pin. power-check analyses each declared state, including possible back-power into an unpowered domain.
