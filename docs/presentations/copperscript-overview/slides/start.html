26 / GET STARTED

Start with a small circuit.

git clone https://github.com/andenore/CopperScript
cd CopperScript
cargo install --locked --path crates/copper

# orient, then check and compile
copper agent-guide
copper check examples/valid_board/board.copper

# simulate a low-noise preamp
copper sim examples/simulation/preamp/board.copper

Website

andenore.github.io/CopperScript

Libraries

github.com/andenore/CopperLib

Review in the browser

andenore.github.io/CopperReview

Getting started needs Git and the Rust toolchain; KiCad is optional. The agent guide is the first command for both people and agents. The quick start checks a small fixture, then runs the preamp’s simulation benches, which finish in well under a second. The website has the live routing lab and compiler demo, and CopperReview opens boards in the browser.
