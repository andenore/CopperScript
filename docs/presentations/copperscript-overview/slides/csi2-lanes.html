10 / DIFFERENTIAL PAIRS AND SKEW

A four-lane CSI-2 link, matched in source.

// the clock pair; D0–D3 are declared the same way
constraint routing(CSI_CLK_P) {
    kind = differential; partner = CSI_CLK_N;
    width = 0.14mm; pair_gap = 0.26mm;
    max_skew = 0.1mm;           // P against N
    target_impedance_ohms = 100;  // differential
    target_single_ended_ohms = 50;
    allowed_layers = "F.Cu"; max_vias = 0;
    layer_group = "csi";       // clock + lanes
}
constraint length_match(CSI_CLK_P, CSI_CLK_N,
        CSI_D0_P, CSI_D0_N, … CSI_D3_P, CSI_D3_N) {
    id = "csi-lanes"; max_skew = 0.5mm;
}

  • Before routing, impedance is screened against the declared stack-up
  • The router compensates skew inside each pair, then tunes the group to its longest lane with bumps or serpentines
  • A miss is a DRC-LENGTH-MATCH review warning, never hidden
Signal-integrity intent for a MIPI CSI-2 D-PHY link with a clock and four data lanes. Each pair gets a differential routing rule: partner, width and gap, its own skew budget, differential and single-ended impedance targets, the layers it may use and a layer group that keeps clock and data on the same layers. One length_match group holds all ten nets to 0.5 mm. The output on the right is copper si-check on a four-lane fixture with a six-layer stack-up, abridged: all five pairs screen at 99.7 ohm differential and 51.9 ohm single-ended, inside their targets. During routing, intra-pair skew is compensated first, then each lane of the group is tuned towards the longest; tuning_style chooses bumps or serpentines, and tuning_group bends adjacent lanes together. Skew and length misses are reported as review warnings rather than silently accepted. Impedance screening is an estimate from the declared stack-up, not a field-solver sign-off.
