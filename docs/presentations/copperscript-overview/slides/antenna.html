12 / ANTENNA SYNTHESIS

Declare the band. Synthesize the copper.

constraint antenna(ANT1.FEED) {
    name = "bt";
    x = 18mm; y = 0mm;
    width = 22mm; height = 6mm;
    ground = GND;
    bands = "2400 MHz-2483.5 MHz";
    track_width = 1mm;
    // pasted from synthesize-antenna
    geometry =
      "monopole height=5.3mm length=22.77mm";
    tuned_for = "sha256:fadfbf76…95ba";
}

The digest binds the geometry to this board’s outline, stack-up, ground and feed. Change one and the board stops compiling until synthesis runs again.

From the antenna synthesis example. You reserve a board-edge region, name the ground and the band. copper synthesize-antenna tunes the trace on a pinned pure-Rust full-wave FDTD model of this board, polishes height and length, fits an L-section match and verifies the result on a fine mesh, then prints the geometry and digest to paste into the source. The first-order quarter-wave template resonates at 2.72 GHz; the synthesized monopole resonates at 2.37 GHz and stays better than −12.3 dB across the band once matched, with 0.85 nH series and 2.54 pF shunt and 86 % radiation efficiency. The figure is drawn from the recorded synthesis data on the project website. It is simulation evidence for one model: the enclosure, cables and nearby parts are not in it, so bench tuning and testing remain.
