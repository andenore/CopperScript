Fab settings and panels are source too.

panel ExamplePanel {
    spacing = 2 mm; fiducials = 3;
    rails = { top = 5 mm; bottom = 5 mm; };
    mouse_bite = { drill = 0.5 mm;
        pitch = 0.75 mm; inset = 0.25 mm; };
    board MONO { … at = (0 mm, 0 mm); }
    board IFA { … at = (42 mm, 0 mm); }
    tab mono_top { board = MONO;
        side = top; at = 8 mm; }
}

A board’s build block keeps its fab profile and routing settings in source; the command line still overrides it.

examples/panel after copper panelize, fill and DRC (0 violations): one board for the whole panel.

The panel example places the two routed antenna boards on one fabrication panel with rails, tabs, mouse bites, fiducials and a tooling hole. copper panelize writes one KiCad board for the panel, so the native fill, DRC and plotter run on it unchanged; here the DRC reported zero violations and zero unconnected items, with the open antenna ends excused by the panel report. Every inside corner of the routed outline comes out rounded to the cutter radius. A board’s build block keeps the fab profile, placement and routing settings in source. The code is abridged from examples/panel/panel.copper.
