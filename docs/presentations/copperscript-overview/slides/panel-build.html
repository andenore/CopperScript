13 / BUILD SETTINGS AND PANELS

Fab settings and panels are source too.

board Example {
    build {
        fab_profile = "jlcpcb-six-layer";
        routing { effort = balanced; time_budget = 600s; }
    }
}

panel ExamplePanel {
    spacing = 2 mm; fiducials = 3;
    mouse_bite = { drill = 0.5 mm; pitch = 0.75 mm; };
    board MONO { source = "…/board.copper"; … }
    tab mono_top { board = MONO; side = top; at = 8 mm; }
}

Settings in the board

The build block feeds route-board and copper build; the command line still overrides it.

One panel board

copper panelize writes rails, tabs, mouse bites and fiducials as one board.

Checked like any board

Native fill and DRC run on it unchanged; a fab preset checks the fab’s rules.

Two smaller features that remove hidden state. A board’s build block keeps its fab profile, placement and routing settings in source instead of a Makefile; precedence is command line, then source, then compiler default. A panel document places already-routed boards with rails, tabs, mouse bites, fiducials and tooling holes, and copper panelize writes one KiCad board for the whole panel, so the native fill, DRC and plotter run on it unchanged. A fab preset fills in the fab’s values and checks the panel against its rules. Both excerpts are abridged from the language reference and the panel example.
