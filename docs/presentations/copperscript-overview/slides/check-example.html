Located

File, line and subject: the agent edits the right place, not a guess.

Named

A stable code that copper explain describes, so the agent learns the rule.

Deliberate

An open pin needs a no_connect with a reason, so omissions and decisions differ.

Real output from the repository’s invalid-board example, trimmed to two of its twelve findings. The first is a rating violation the compiler found because the part declares its voltage range. The second shows how CopperScript separates mistakes from decisions: a pin left open must be marked no_connect with a reason, otherwise it is reported. Findings can also carry machine-applicable fixes, which an agent applies only when the source still holds the original text.
