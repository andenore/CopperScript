17 / WORKS WITH KICAD

KiCad stays in the loop.

CopperScript is the source; KiCad is an export target, a library source and an independent check. Finish, review or hand over a design in KiCad at any point.

Native KiCad projects

Every board command writes .kicad_pcb, .kicad_pro and its footprint library; export-kicad writes a KiCad schematic.

KiCad’s own libraries

Footprints and 3D models come from KiCad’s repositories, pinned by commit in copper.mod.

An independent check

--verify kicad refills and runs DRC with kicad-cli; compare-cam compares two plots.

Reference layouts

copper view --reference overlays a KiCad board, such as a manufacturer’s evaluation layout, aligned on the package pads.

CopperScript does not replace KiCad. Every PCB-producing command writes a complete KiCad project with its own footprint library, so the board opens in KiCad without setup, and copper export-kicad writes a KiCad 8 schematic as a derived artifact. Footprints and 3D models come from KiCad’s official repositories pinned by commit. copper build can verify with KiCad 10 instead of the native filler and DRC, and copper compare-cam compares the native and KiCad plots. copper view --reference overlays a reference KiCad board aligned on the package pads, which is how blocked package exits are compared with a manufacturer’s layout. There is no Altium integration, and the KiCad board importer of the old Python implementation has not been ported.
