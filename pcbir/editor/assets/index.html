Persistent source constraints










Scroll to zoom; right-drag to pan. Focus the board: arrows move by one snap (Shift: ten); R rotates to the next allowed angle; +/− zoom; F fits. Escape cancels a gesture. Tab/Enter selects a footprint. Temporary placement and source history are separate.


Mechanical features









Dimensions use exact CopperScript units (e.g. 2.2mm). Position is (xmm, ymm); vertices are [(xmm, ymm), ...]. Holes are NPTH; plated holes must be electrical components. Imported profiles remain read-only.


Closed line/arc path

Edit all joined endpoints together. JSON entries use id, kind (line/arc), start/end, and mid for arcs; coordinates are CopperScript length-pair literals. Unsupported concave curved paths fail rather than heal.
